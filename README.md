# MonsterMac

노치 왼쪽의 검은 버튼으로 Mac의 화면 유지를 켜고 끄는 앱입니다.

[최신 DMG 내려받기](https://github.com/quino0627/MonsterMac-releases/releases/latest)

## 설치

DMG를 열고 `MonsterMac.app`을 `Applications`로 옮기세요. macOS 13 이상에서 실행됩니다. Apple Silicon과 Intel 실행 파일을 포함합니다.

Homebrew로 설치할 수도 있습니다.

```sh
brew tap quino0627/monstermac https://github.com/quino0627/MonsterMac-releases
brew install --cask quino0627/monstermac/monstermac
```

## 사용

- 화면 유지 아이콘 클릭: 켜기 또는 끄기. 대기 중에는 아이콘만 보이고, 켜지면 원형 아이콘이 민트색으로 바뀝니다.
- 왼쪽 아이콘 또는 물리 노치에 마우스를 1초 올리면 펼쳐집니다. 마우스를 빼면 다시 접힙니다.
- 화면 유지, 뽀모도로, RAM 사용량을 작은 원형 상태 아이콘으로 표시합니다. 아이콘과 원형 게이지를 하나로 묶습니다.
- 펼친 영역은 물리 노치와 왼쪽에 붙인 부분을 모두 덮습니다. 둥근 우하단에 틈이 생기지 않도록 검은 면으로 연결합니다.
- 위젯은 노치 아래로 부드럽게 나오고 위로 접힙니다. ‘동작 줄이기’를 켜면 즉시 전환합니다.
- 아이콘을 좌우로 드래그해서 순서를 바꿀 수 있습니다. 맨 왼쪽 아이콘을 접힌 노치에 표시하며, 순서는 저장합니다.
- 뽀모도로는 집중 25분·휴식 5분을 반복합니다. 아이콘을 클릭하면 시작하거나 멈춥니다. 오른쪽 클릭 메뉴에서 초기화할 수 있습니다. 구간이 바뀌면 알림음을 냅니다. 화면 유지와 별도로 동작합니다.
- RAM 사용량은 5초마다 갱신합니다. 아이콘에 마우스를 올리면 사용 용량을 볼 수 있습니다. 접힌 노치의 기본 표시가 RAM이면 클릭해서 펼치고, 뽀모도로이면 클릭해서 시작하거나 멈춥니다.
- 오른쪽 클릭: 메뉴와 종료.
- 연결된 모든 화면에 버튼을 표시합니다. 노치가 없는 화면에는 위쪽 가운데에 검은 가상 노치를 만들고 왼쪽에 버튼을 붙입니다.
- 어느 화면에서 켜거나 꺼도 모든 버튼의 상태가 함께 바뀝니다. 화면 연결과 배치가 바뀌면 위치를 다시 맞춥니다.

1.1.0부터는 설치 후 도우미를 처음 한 번 허용합니다. 노치 버튼을 누르고 ‘설정 열기’를 선택한 뒤, 시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램에서 MonsterMac을 허용하세요. 이후에는 켜고 끌 때마다 암호를 묻지 않습니다. 앱은 암호를 읽거나 저장하지 않습니다.

끄거나 앱을 종료하면 잠자기 설정을 복구합니다. 앱이 강제 종료되거나 도우미가 다시 실행되어도 남은 기록으로 복구합니다. Mac의 암호 요구 설정과 수동 잠금은 유지합니다. 오른쪽 클릭 → ‘도우미 권한 해제’로 등록을 해제할 수 있습니다. Homebrew 삭제 때도 도우미 등록을 해제합니다.

배터리 사용 중 잔량이 20% 이하이거나 Mac의 온도가 높으면 기능을 끕니다. 다른 잠자기 방지 앱의 세션은 끝내고 사용하세요.
